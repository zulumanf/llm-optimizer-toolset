# RecommendedFirst remote MCP connector

Grok (grok.com Connectors, Grok Bot, xAI API) reads this app's visibility
data over Model Context Protocol at `https://app.recommendedfirst.com/mcp`
— read-only, bearer-token auth.

Setup, token minting, example prompts, and security notes:
