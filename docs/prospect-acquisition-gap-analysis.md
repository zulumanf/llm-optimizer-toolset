## Cross-cutting findings

1. **The measurement core is the asset; don't fork it.** Prospect benchmarks in the slice read existing `mentions`/`scores` for a linked company — zero new measurement code, zero risk to client denominators. Dedicated prospect-owned runs (Phase 2) require exactly two changes: relax `startRun`'s active-status check and teach `listCompaniesForProject` that prospect subjects aren't client subjects.
2. **Spec 011 conflict must be resolved before sequence automation.** Its red-level "no send path may exist" contradicts migration 020's gated send. The acquisition layer sidesteps this in the slice (drafts + manually recorded sends only), but Phase 3 needs a recorded decision.
3. **No email infrastructure exists.** Any "sent/delivered/bounced" tracking beyond manual recording requires a live, verified ESP or Gmail connection — currently `implemented_unverified`. Treat all engagement claims accordingly.
4. **Public audit pages are the platform's first anonymous content surface.** The security bar: high-entropy tokens, published-snapshot rendering only, revocation, expiry, no sequential ids, middleware allowlist, and tests that revoked/expired/wrong tokens 404.
